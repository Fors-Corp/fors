# Security policy

Fors is pre-alpha and does not yet generate code, so there is no supported
release line. Even so, a defect in the compiler front end (a crash or hang on
crafted input) or in the specification's soundness rules is worth reporting.

Please report privately through GitHub's
[private vulnerability reporting](https://github.com/Fors-Corp/fors/security/advisories/new)
rather than a public issue. Expect an acknowledgement within a week.
